How to route audio

After adding a peer, open the mesh-aware patchbay at /client/mesh.html on the main CM5Audio dashboard port (default 8182). It embeds the normal patchbay and adds live green/red connection indicators to both outgoing and incoming remote peer nodes. Route the remote source into local processing or devices, and route local audio into the remote sink.

Configure a connection on only one side for each pair of CM5Audio instances. One connection is bidirectional; configuring the same pair on both machines creates duplicate streams.

Disconnected peers retain their patchbay endpoint identities and saved cables. Removing a peer here stops reconnect attempts but intentionally leaves its disconnected endpoints in the graph so existing routing is not silently deleted.
